# 微信文章发布系统 - 迁移与打包运行指南

本系统已完成**前后端一体化打包优化**。
**在目标电脑（另一台电脑）上运行，完全不需要安装 Node.js，也不需要配置复杂的开发环境！**

---

## 一、如何将项目拷贝到另一台电脑（极重要！）

请将本项目的文件夹压缩打包或直接拷贝至移动硬盘/U盘。

### 1. 必须要拷贝的文件和目录：
- `backend/` （后端核心服务与代码）
- `frontend/dist/` （**极度关键**：前端打包后的静态资源，有了它目标机**完全不需要安装 Node.js/npm**）
- `data/` （本地数据库与配置目录，包含文章数据与设置）
- `一键启动.bat`
- `一键安装依赖(首次运行).bat`
- `一键停止.bat`
- `README_部署与打包说明.md`

### 2. **千万不要拷贝**的冗余目录（非常大，且拷贝会导致报错）：
- ❌ `frontend/node_modules/` （**严禁拷贝**！体积数百兆，且目标电脑根本用不到它）
- ❌ `backend/.venv/` （**不建议拷贝**！因为 Python 虚拟环境绑定了原电脑的路径，换电脑后路径不一致可能失效。在另一台电脑上直接双击 `一键安装依赖(首次运行).bat`，1分钟即可全新自动生成）
- ❌ 任何 `__pycache__` 缓存文件

> **快速打包技巧**：在当前电脑上，删除（或排除）`frontend/node_modules` 和 `backend/.venv` 两个文件夹后，直接将整个文件夹打包为 `.zip` 压缩包（打包后体积通常只有几十兆），传输极快！

---

## 二、另一台电脑的环境要求

1. **操作系统**：Windows 10 或 Windows 11 (64位)
2. **Google Chrome 浏览器**：
   - 目标电脑必须安装了官方 Google Chrome 浏览器（头条自动化发布依托本地 Chrome）。
3. **Python 环境**：
   - 目标电脑只需安装了 **Python 3.10 或更高版本**（推荐 3.10 ~ 3.12）。
   - 安装 Python 时，**务必勾选【Add Python to PATH】**（添加到系统环境变量）。

---

## 三、另一台电脑的操作步骤（只需 2 步）

### 第一步：首次运行（安装依赖）
解压后，在项目根目录下找到：
👉 **双击运行：`一键安装依赖(首次运行).bat`**
- 脚本会自动创建纯净的虚拟环境并从清华大学高速镜像源下载所需依赖；
- 整个过程大约只需 1~2 分钟，提示“环境安装成功”即可按任意键关闭。

### 第二步：日常使用（一键启动）
👉 **双击运行：`一键启动.bat`**
- 脚本会自动启动后台发布服务；
- 并在默认浏览器中自动弹出打开 `http://127.0.0.1:8000`；
- 进入网页后，即可直接抓取微信文章、AI 改写、并一键发布到今日头条！

### 退出与停止
👉 **双击运行：`一键停止.bat`** 即可安全退出服务。

---

## 四、关于今日头条账号登录（新电脑首次使用）

在新电脑上首次点击【发布到今日头条】时：
1. 程序会自动弹出一个专门用于发布的 Chrome 浏览器独立窗口；
2. 此时若头条未登录，会自动跳转到今日头条官方登录页；
3. 用今日头条 App 扫码登录一次；
4. 登录后后续所有发布均会**持久化记住登录状态**，无需重复扫码！
